¿Qué es el préstamo a domicilio?

El préstamo a domicilio permite llevar a casa libros de la Colección General para estudiar o investigar fuera de la biblioteca. Quien recibe el libro debe cuidarlo y devolverlo a tiempo.

¿Qué ejemplares se prestan?

  • El e.1 se reserva para consulta en sala.
  • Para préstamo a domicilio, se prestan del e.2 en adelante.

Renovaciones

  1. El préstamo se registra en la cuenta del usuario.
  2. Para renovar, el usuario no debe tener adeudos ni multas.
  3. Cada préstamo se puede renovar hasta tres veces.

Reglamento

Toda renovación, deberá hacerse en la fecha de vencimiento, previa presentación del material tomado en préstamo.

Reglamento de Servicios Bibliotecarios del Sistema de Bibliotecas
